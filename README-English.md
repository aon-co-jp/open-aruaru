# open-aruaru (a.k.a. iLumi Project)

**Making "it never disappears" the default, in pure Rust.**

Paid items in a 3D online game. A financial balance. The data you've spent years building.
open-aruaru is a project that keeps them alive 24/7/365 — running one language,
Rust, all the way from the screen down to the deepest layer of the database.

> ⚠️ This repository is the entire development workspace (**operated as Private**).
> Public products are published from each project's own independent repository.

---

## Why This Is Exciting

Normally, shipping one web service means juggling different languages at every seam — JS on the front, Go/Python on the backend, some C++ middleware for the database — and bugs love to hide in those seams. open-aruaru does it differently: **it's Rust from the UI to the storage engine, full stop.** The types connect end to end, so the more you build, the harder it gets to break.

At the center is **open-runo** — built with real respect for WunderGraph Cosmo (the excellent Go-based GraphQL federation layer), reimagined in pure Rust with a lightweight predictive-decision layer that asks a simple question first: *do we even need to ask the server?* That single idea drives both speed and lower server load, and the rest of the product line radiates outward from it.

## The Product Line

| Product | In one line |
|---|---|
| **open-web-server** | The three-tier front door — flexible enough to sit in front of any language like Apache/Nginx, with a no-contract, locally self-learning autoconf built in |
| **open-runo** | The heart of the project — arbitrates real triple commits over a dual QUIC + gRPC ingress |
| **aruaru-db** | An append-only, ironclad store that tells network corruption apart from disk corruption with dual checksums |
| **open-client** | Built on Tauri v2 — lighter and faster than Electron, with predictive caching that trims server round-trips |
| **OpenCosmo** | GraphQL federation, rebuilt in pure Rust + Poem |
| **OpenLLM (aruaru-llm)** | The in-house LLM foundation that will grow open-runo's predictor into a real model |
| **OpenDirectX / OpenCuda** | Bringing 3D game graphics and GPU compute into the Rust ecosystem |
| **Open-eGov / open-e-gov** | Digital government services on Rust + Poem + OpenRuno |
| **OpenRedmine / OpenWordPress** | Familiar tools, running on the same three-tier safety net |

Each piece is simple on its own — but the moment they're all speaking the same language through the same arbiter, the possibilities start multiplying.

## Why You Can Start Right Now

- **A layout that never confuses you** — one straight line: `open-web-server → open-runo → aruaru-db`. No overlapping responsibilities.
- **Ops you don't have to hand-roll** — Linux config files are generated by the self-learning autoconf. AlmaLinux, RHEL, Rocky, Ubuntu, Mint — all covered.
- **Moving day isn't scary** — learned "smarts" are auto-backed up to the cloud via rclone. Reinstall the OS, restore in one command.
- **One clear learning path** — [The Rust Book](https://doc.rust-lang.org/book/), [Poem](https://docs.rs/poem/latest/poem/), and [Tauri v2](https://v2.tauri.app/) are all you need to understand this project end to end.

## Who This Should Spark Something In

- Anyone who's ever wished they could write the frontend, backend, and database in one language, start to finish.
- Anyone who knows exactly how much it matters that a game item or a bank balance never just vanishes.
- Anyone who loves what Cosmo does in Go and has a feeling Rust could do it faster and lighter.
- Anyone who wants the AI running on their own machine to still be smart tomorrow — and after a fresh install, and after a new laptop.

By the time you finish reading this, your next idea already has a place to stand: on top of open-web-server, open-runo, and aruaru-db. What you build next is up to you.

## Technical Stack Principles

- **Language**: Pure Rust (frontend is TypeScript, framework-agnostic)
- **Web**: [Poem](https://docs.rs/poem/latest/poem/) + Tokio
- **Database**: DUAL DATABASE (PostgreSQL + aruaru-db) as the baseline, with support for 9 engines
- **AI**: Self-learning, with no dependency on a paid LLM contract (gets smarter the more it's used)
- **Naming**: crates as `open-runo-*` / Rust paths as `open_runo_*` / env vars as `OPEN_RUNO_*`
