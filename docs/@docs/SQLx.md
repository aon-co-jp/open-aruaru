## aruaru での使い方

- VersionLess Storage: `src/storage/`
- `AnyPool` — PostgreSQL / SQLite 切替
- プレースホルダ: `$1`, `$2`（PostgreSQL 形式）
- マイグレーション: `sqlx migrate` または `src/storage/migrate.rs`
