### 2.1 インフラ・VPS

| 機能 | 状態 | 主要ファイル |
|------|------|-------------|
| VPS アップロード | ✅ | `F:/aruaru/deploy/upload-vps.ps1`, `F:/aruaru/deploy/vps-full-setup.sh` |
| nginx + certbot 自動セットアップ | ✅ | `F:/aruaru/deploy/vps-full-setup.sh` |
| SSH 接続確認 | ✅ | `check_vps_connection`, `F:/aruaru/deploy/cursor-vps.ps1` |
| **ドメイン登録 → 自動 HTTPS** | ✅ | `F:/aruaru/src/https_auto.rs`, `F:/aruaru/src/https_cert.rs` |
| **証明書自動更新** | ✅ | `certbot renew` 24h 間隔（`renewal_interval_secs`） |
| vhost 生成・nginx 配置 | ✅ | `F:/aruaru/src/vhost.rs` |
| E/F ドライブ同期 | ✅ | `F:/aruaru/deploy/sync-drives.ps1` |

**自動 HTTPS の流れ:**
1. ドメイン登録（`add_platform_domain` / `add_domain`）
2. 即時バックグラウンドで certbot
3. 失敗時 `data/https-queue/` にキュー → 5 分監視で再試行
4. 成功時 `https_enabled=1`、主ドメインなら `public_url` を `https://` に更新

**設定（VPS `data/config.toml`）:**
```toml
[https_monitor]
enabled = true
auto_configure = true
certbot_email = "実メールアドレス"  # 必須
web_server = "nginx"
renewal_interval_secs = 86400
```
